# Custom Linear Regression Library

A robust, pure NumPy-based custom linear regression library. Designed to be lightweight and zero-dependency (other than NumPy/SciPy), it implements all major regression features from scratch.

## Features

### Linear Regression

This library strictly adheres to the OLS regression steps:

1. **ADD INTERCEPT**: Fully integrated intercept handling with `fit_intercept=True` and Scikit-learn style `.coef_` and `.intercept_` properties.
2. **FORWARD SELECTION**: Stepwise greedy feature addition based on model evaluation score.
3. **BACKWARD ELIMINATION**: Stepwise greedy feature removal to find the optimal subset.
4. **L1 REGULARIZATION**: Lasso regularization via Gradient Descent (`penalty='l1'`).
5. **L2 REGULARIZATION**: Ridge regularization via Gradient Descent or Closed-form solver (`penalty='l2'`).
6. **MISSING VALUES**: Robust imputation strategies (`mean`, `median`, `forward_fill`, `backward_fill`) and `drop_missing`.
7. **OUTLIERS**: Detection and handling using Z-score and IQR strategies.
8. **NORMALITY**: Shapiro-Wilk, Anderson-Darling, Jarque-Bera, and Kolmogorov-Smirnov tests.
9. **MULTICOLLINEARITY**: Variance Inflation Factor (VIF) scores and Correlation matrices.
10. **HETEROSCEDASTICITY**: Breusch-Pagan, White, and Goldfeld-Quandt tests.
11. **VISUALIZATION**: Matplotlib-based diagnostic plots and pure-text ASCII/ANSI visualizers for environments without graphical libraries.
12. **PREDICTION**: Fast, vectorized predictions maintaining handling for missing and outlier data.

### K-Nearest Neighbors Regression

Complete KNN implementation with advanced features:

- **Distance Metrics**: Euclidean, Manhattan, Minkowski (fully customizable)
- **Weighting Strategies**: Uniform averaging or inverse-distance weighting
- **Data Preprocessing**: Automatic handling of missing values and outliers
- **Feature Scaling**: Z-score normalization for distance computation
- **Feature Importance**: Permutation-based importance analysis
- **Hyperparameter Tuning**: Support for k, metric, and weights optimization
- **Best K-Value Detection**: Automatically identifies and displays optimal K value with R² score
- **Scikit-Learn Compatible**: Standard `fit()`, `predict()`, `score()` API

## Real-World Case Study: Thrissur House Price Prediction

The model was trained and evaluated on real house-listing data scraped from **Housing.com** for Thrissur, Kerala — and later augmented to 1000 samples using statistically faithful synthetic data.

### Dataset

| Version | Rows | Source |
|---------|------|--------|
| Original | 186 | Scraped from Housing.com |
| Augmented | **1000** | 186 real + 814 synthetic (locality-aware Gaussian augmentation) |

The synthetic rows were generated by `augment_dataset.py`, which:
- Learns the **per-locality mean and standard deviation** of Area, BHK, and price-per-sqft from the real data.
- Samples new values from a Gaussian distribution around those statistics.
- Adds **44 additional real Thrissur localities** to broaden geographic coverage.
- Preserves the exact CSV schema so the training pipeline works unchanged.

## Experiment Journey & Results (Proof)

### Stage 1 — Baseline (Raw Features, No Encoding)

One-hot encoding the `Locality` column (86 unique localities, only ~2 samples each) caused massive overfitting.

- **Training R²**: ~0.99 (memorized training set)
- **Testing R²**: ~0.30 (poor generalization)

**Problem identified**: Too many locality dummy variables relative to the number of samples.

---

### Stage 2 — Target Encoding Only (185 rows)

Replaced one-hot encoding with **Target Encoding** — each locality is represented by its mean price-per-sqft computed on the training set, with a global fallback for unseen localities.

- **Training R²**: 0.6096
- **Testing R²**: **0.5304**

Significant improvement in generalization.

---

### Stage 3 — Log Transform + Polynomial Features (185 rows)

Added `log(Price)` as the training target, plus polynomial features `Area²` and `Area × BHK`.

- **Training R²**: 0.8596 ↑ (excellent fit on training)
- **Testing R²**: **0.4775** ↓ (score dropped!)

**Conclusion — Bias-Variance Tradeoff:** With only 185 rows and 86 localities, complex features caused overfitting. The model memorized the training set but generalized poorly.

---

### Stage 4 — Dataset Augmented to 1000 Rows ✅ BEST RESULT

The root cause of all previous stages was **insufficient data**. After augmenting the dataset to **1000 rows** using the locality-aware Gaussian method:

## Basic Usage

### Linear Regression

```python
import numpy as np
from custom_linear_regression import LinearRegression

# 1. Define Data
X = np.array([[1.0], [2.0], [3.0], [4.0]])
y = np.array([2.0, 4.1, 6.0, 8.2])

# 2. Train Model
model = LinearRegression(
    fit_intercept=True,
    penalty='l2', 
    alpha=0.1, 
    solver="closed"
)
model.fit(X, y)

# 3. Predict & Score
print("Coef:", model.coef_)
print("Intercept:", model.intercept_)
print("Prediction:", model.predict([[5.0]]))
print("R^2 Score:", model.score(X, y))
```

### K-Nearest Neighbors Regression

```python
import numpy as np
from custom_linear_regression import KNNRegression

# 1. Define Data
X_train = np.array([[1.0, 2.0], [2.0, 3.0], [3.0, 4.0], [4.0, 5.0]])
y_train = np.array([2.5, 4.0, 6.0, 8.0])
X_test = np.array([[2.5, 3.5]])

# 2. Train Model
model = KNNRegression(
    k=3,                    # Number of neighbors
    metric='euclidean',     # Distance metric
    weights='distance',     # Weighting strategy
    scale=True             # Z-score scaling (recommended)
)
model.fit(X_train, y_train)

# 3. Predict & Score
print("Prediction:", model.predict(X_test))
print("R^2 Score:", model.score(X_test, np.array([5.0])))

# 4. Feature Importance
importances = model.compute_feature_importances(X_test, np.array([5.0]))
print("Feature Importances:", importances)
```

**Distance Metrics Available**: `'euclidean'`, `'manhattan'`, `'minkowski'`

**Weighting Strategies**: `'uniform'` (simple average), `'distance'` (inverse-distance weighted)

See [`KNN_REGRESSION.md`](KNN_REGRESSION.md) for comprehensive KNN documentation.

## Exceptions

The library defines specific custom exceptions for robust error handling under `custom_linear_regression.exceptions`:
- `NotFittedError`: Raised if prediction is called before the model is fitted.
- `OptimizationFailedError`: Raised if the Gradient Descent algorithm diverges.
- `DataQualityError`: Raised if the dataset becomes empty due to aggressive missing-value or outlier drops.

```python
from custom_linear_regression import LinearRegression, NotFittedError

try:
    model = LinearRegression()
    model.predict([[1.0]])
except NotFittedError as e:
    print(e)
```
